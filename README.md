# AI Web Development Automation Platform

A platform that transforms web application ideas into production-ready deployments using AI automation. Built with Claude Code (Minimax M2.7 API), NeonDB, and Vercel.

## Vision

From idea to production URL in minutes — no code, no developers, no compromise on quality.

## Tech Stack

- **AI Runtime**: Claude Code with Minimax M2.7 API
- **Database**: NeonDB (serverless PostgreSQL)
- **Deployment**: Vercel
- **Control Plane**: Python FastAPI
- **Agent Runtime**: Claude Code CLI in Docker containers
